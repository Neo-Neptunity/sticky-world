# 付箋ワールド 開発用のテスト

MOD 本体は `sticky-world/mod/`。配る zip に入れたくないので、テストは本体に置かず、ここにまとめる。
`unit.mjs` は `node` だけで動く。`browser.mjs` は、Edge（なければ Chrome）が入っていれば動く。どちらも EP_MODs から流す。

| ファイル | 内容 | 使い方 |
|---|---|---|
| `unit.mjs` | 画面を持たない部品の試験：ID とファイル名・月のフォルダ（同期で分かれたものも）・居場所の名前・**読んだ出来事の確かめ（なりすまし・壊れた JSON・制御文字・長すぎる文字・パスを含むファイル名）**・まとめ上げ（直す・消すは本人だけ、読む順に関係なく同じ結果、時計のずれ）・地図・**共有フォルダを2人で使う（作る・届く・居場所はファイルが増えない・新しいファイルだけ読む・開き直しは覚えた分を読まない・読めないファイルは飛ばす・読み直す・書く許可が無い・覚える場所がいっぱい）**・manifest・書き方の決まり | `node sticky-world/dev/unit.mjs` |
| `browser.mjs` | 本物の `index.js` を、ヘッドレスの Edge で動かす。画面を PNG に撮る | `node sticky-world/dev/browser.mjs [出力フォルダ] [--scenario=…] [--w=1280 --h=760] [--dpr=2]` |
| `fake-host.mjs` | 偽の explorer_plus。メモリの中の共有フォルダと、それを見る人ごとの `explorerPlus`。本物と同じく ID が合わなければ断り、名前を変えたらフォルダを読み直す | |
| `seed.mjs` | にぎわっているワールドの種。8人・2つの月・話題と返信・アイデア12枚・書庫の本9冊・直し・消し・居場所6人分 | |
| `stage.mjs` | MOD のファイルを一時フォルダにコピーして、node で読めるようにする | |

## browser.mjs のシナリオ
- `look`：広場 → アトリエ → 付箋のカード → 書庫 → 書く画面 → 名札 → 夜 → 狭い画面。見た目を調整するときに使う
- `welcome`：ワールドの無いフォルダ → 作る → 名札を作る → 空のワールド
- `flow`：書く・リアクション・返信・直す・ほかの人の新着が届く・**新着で欄が作り直されても書きかけが残る**・ドラッグで動かす・ボードをダブルクリックして貼る・立ち止まると居場所を知らせる・消す

## 確かめられないこと
- 本物の explorer_plus の中での動き。偽の本体で代用している。とくに、ファイルを作る許可の画面・名前の変更のあとのフォルダの読み直し・キーが MOD の画面へ届くか
- OneDrive の同期そのもの。遅れ・重複フォルダ・クラウドにだけあるファイルの読み込みは、偽のフォルダで形だけまねている
- 50人が何か月も使ったときの重さ。ファイルの数が数千を超えたら、開くときの時間を測る
