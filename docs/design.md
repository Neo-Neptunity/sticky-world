# 付箋ワールド 設計

共有フォルダを、みんなで付箋を貼り合う 2.5D のワールドにする MOD。0.1.0。

## ねらい

- 身近な大勢、最大で 50 人ほどが、同じ場所に集まって付箋を貼る。アイデア出し・日常の話題・情報の置き場を、これ一つで済ませる
- ファイラーらしさは出さない。アバターで歩き回る、メタバース寄りの見た目にする
- サーバーは使わない。OneDrive や NAS の共有フォルダを、そのまま「場」にする

## 場所

| 場所 | 種類 | 中身 |
|---|---|---|
| 広場 | `talk` | 話題とお知らせ。返信できる。掲示板に新しい6件が貼られる |
| アトリエ | `idea` | 大きなボードに、アイデアの付箋を自由な位置に貼る。誰でもドラッグで動かせる |
| 書庫 | `shelf` | 題名つきの本を、名前の付いた棚に置く。探せる |

- 場所に入ると、右に欄が開く。狭い画面では下に開く。欄に隠れないように、カメラを反対側へずらす
- 話題と本には、そのフォルダのファイルを添えられる。押すと開く。名前で覚えるので、PC がちがっても同じファイルを指す
- 景色はフォルダの名前から決める。同じフォルダなら、誰が見ても同じ並びになる。時刻で夕方・夜の色になる

## データ

すべて、開いたフォルダの中の `.付箋ワールド` に置く。

```
.付箋ワールド/
  はじめに.txt               MOD を入れていない人向けの説明
  2026-10/<ID>.json          出来事1つにファイル1つ。月は世界時で決める
  here/<誰~時刻~x~y>.txt     居場所。1人1ファイルで、名前だけを変える
```

- **書き込みは「新しく作る」と「自分の居場所のファイルの名前を変える」だけ。** ほかの人のファイルは書き換えないので、同期でぶつからない
- 出来事は `hello`・`note`・`edit`・`move`・`react`・`del` の6種類。付箋を直す・動かす・消すも、新しい出来事として足す。消すのは消した印を付けるだけで、ファイルは残る
- ID は「時刻36進9桁-書いた人6文字-偶然4文字」。書いた人は中身ではなくファイル名から決める
- 全部の出来事を時刻と ID の順に並べて、毎回いちから今の姿を作る（`fold`）。読む順に関係なく、同じ結果になる
- 直す・消すは書いた本人だけ。動かす・リアクションは誰でもできる
- 読んだファイルは信じない。形が合わないものは捨てる。文字は画面に `textContent` でだけ入れる
- 同時に月のフォルダを作って、OneDrive が `2026-10-PC名` のように分けても、同じ月として読む

## 読み込みと新着

- 開くときは、新しい月から順に全部読む。読み終わった月は、ファイルの名前と中身を `ep.storage` に覚えておく。次に開くときは、フォルダにあって覚えていない分だけを読む
- 新着は数秒おきに確かめる。間隔は設定で変えられ、既定は5秒。見るのは新しい2か月と居場所だけで、60回に1回、古い月も見直す。読むのは知らないファイルだけ
- 本体の `onChanges` は開いているフォルダの直下しか知らせないので、奥の新着は確かめに行くしかない
- 読めなかったファイルは、3回まで読み直す。形が合わないファイルは1度だけ読んで、あとは飛ばす

## 居場所と気配

- 立ち止まって1.2秒たち、前に知らせてから5秒以上たっていて、24点以上動いていれば、自分の居場所のファイルの名前を変える。90秒ごとにも知らせる
- ほかの人は、居場所のファイルの位置へ歩いて近づける。3分以内なら「いる」、7日以内なら薄く描いて「何分前」を出す
- 名前を変えると、本体がフォルダを読み直して `onFolder` が来る。同じフォルダなら、何もしない

## 名札

- 名前・色・姿は `ep.storage` に置き、ワールドには `hello` の出来事で知らせる。変えたときだけ書く
- 本体に利用者を見分ける仕組みが無いので、自己申告にしている。なりすましは防げない

## 本体に頼んでいること

| 頼みごと | 入ったら |
|---|---|
| 自分のファイルにだけ追記する記録 | 出来事を1人1ファイルにまとめる。ファイルの数が人数分で済む |
| 下の階層の変化の知らせ | 確かめに行くのをやめて、知らせを待つ |
| 利用者の ID と署名 | 名札を本体から取る。なりすましを防ぐ |
| 同期の状態 | 「まだ届いていない」を見せる |
| 画像を貼る | 付箋に画像を付ける |
| 見ていないときの新着の知らせ | 裏のタブでも新着を知らせる |

データの形は「出来事」のままなので、入れ物を差し替えるだけで移れる。

## これから

- 子フォルダを、隣の区画として続けて見せる。部屋と扉で区切る形は、ファイル迷路で失敗したので使わない
- 人がとても増えたときの、古い月の読み込みの軽さ
- 実機での確認。まだ偽の本体でしか動かしていない
